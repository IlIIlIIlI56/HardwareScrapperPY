Coleta de dados

A coleta percorre as seis categorias de componentes no site de origem e reescreve dados/products.json. São algumas centenas de requisições com um pequeno intervalo entre páginas — leva alguns minutos, e dá para cancelar no meio sem perder a base atual.

Builds recomendadas

      

        Cada build parte de um item TOP; as outras 5 peças são escolhidas automaticamente por
        compatibilidade (soquete, tipo de memória, wattagem de fonte) e faixa de preço equivalente.
        A build com melhor índice de valor geral fica destacada no topo.

Metodologia

      
    
        
  • Coleta: scraper/scrape_comprasparaguai.py percorre as páginas de Processador, Placa-Mãe, Memória RAM, Placa de Vídeo, Fonte e HD/SSD e salva em dados/products.json.
    • 
        
  • Especificações: extraídas por regex do nome de cada produto (soquete, chipset, capacidade, velocidade, wattagem, selo 80 PLUS, interface de armazenamento).
    • 
        
  • Performance de CPU/GPU: casada com a base curada em dados/benchmarks.json — por chave exata, por apelido cadastrado por você, ou por similaridade textual (que só aceita o par quando os números do modelo e os sufixos tipo Ti/XT/F são idênticos).
    • 
        
  • Performance de RAM: capacidade x velocidade (MT/s, comparável entre gerações DDR2-5) x um fator de latência real, calculado a partir do CAS Latency quando o anúncio informa (CL convertido para nanossegundos).
    • 
        
  • Performance de Fonte/Armazenamento/Placa-Mãe: fórmula sobre as specs extraídas (wattagem x eficiência, capacidade x interface, tier de chipset).
    • 
        
  • TOP Custo-Benefício: maior índice desempenho/preço de cada categoria, ignorando o quartil mais fraco — para não eleger sempre a peça mais fraca e mais barata.
    • 
        
  • Montagem: a partir de cada peça TOP, as demais são escolhidas pelo melhor índice de valor entre as opções compatíveis e de faixa de preço equivalente.
    • 
        
  • RAM x Plataforma: além do tipo de memória, a escolha considera a velocidade que o CPU+placa-mãe realmente aproveitam (max_ram_mhz) — um kit muito mais rápido do que a plataforma suporta tem o score reduzido, para não pagar por MHz que ficam sem uso.
    • 
        
  • Itens não Pontuados: produtos sem specs suficientes ficam de fora automaticamente, mas podem ser revisados na página Database e reincluídos no cálculo.
    •
