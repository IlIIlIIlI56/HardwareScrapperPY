Builds recomendadas

      

        Cada build parte do item TOP Custo-Beneficio de uma categoria; as demais 5 pecas sao escolhidas
        automaticamente por compatibilidade (soquete, tipo de memoria, wattagem de fonte) e faixa de preco/performance
        equivalente. A build com melhor indice de valor geral fica destacada no topo.
      

      

    


    

      
Metodologia

      
    
        
  • Coleta: script Python (scraper/scrape_comprasparaguai.py) percorre as paginas de Processador, Placa-Mae, Memoria RAM, Placa de Video, Fonte e HD/SSD e salva em data/products.json.
    • 
        
  • Especificacoes: extraidas por regex do nome de cada produto (soquete, chipset, capacidade, velocidade, wattagem, selo 80 PLUS, interface de armazenamento).
    • 
        
  • Performance de CPU/GPU: casada (exata ou por similaridade textual) com uma base de referencia curada em data/benchmarks.json, com valores aproximados de indices publicos de desempenho (estilo PassMark CPU Mark / G3D).
    • 
        
  • Performance de RAM: capacidade x velocidade (MT/s, ja comparavel entre geracoes DDR2/3/4/5) x um fator de latencia real calculado a partir do CAS Latency quando informado no anuncio (CL convertido para nanossegundos -- unico jeito correto de comparar timings entre geracoes diferentes).
    • 
        
  • Performance de Fonte/Armazenamento/Placa-Mae: calculada por formula sobre as specs extraidas (wattagem x eficiencia 80 PLUS, capacidade x interface, tier de chipset).
    • 
        
  • TOP Custo-Beneficio: maior indice performance/preco dentro de cada categoria, ignorando o quartil de performance mais fraco (para nao eleger sempre a peca mais fraca e mais barata).
    • 
        
  • Montagem da build: a partir de cada peca TOP, as demais sao escolhidas pelo melhor indice de valor entre as opcoes compativeis e de faixa de preco equivalente.
    • 
        
  • RAM x plataforma: alem do tipo de memoria (DDR4/DDR5), a escolha da RAM leva em conta a velocidade que o CPU+placa-mae realmente aproveitam (max_ram_mhz em data/benchmarks.json) -- um kit muito mais rapido do que a plataforma suporta tem seu score reduzido na comparacao, para nao pagar por MHz que ficam sem uso.
    • 
        
  • Itens nao pontuados: produtos sem specs suficientes ficam de fora automaticamente, mas podem ser revisados manualmente na pagina Base de dados e adicionados ao calculo.
    •
