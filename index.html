Builds recomendadas

      

        Cada build parte de um item TOP; as outras 5 pecas sao escolhidas automaticamente por
        compatibilidade (soquete, tipo de memoria, wattagem de fonte) e faixa de preco equivalente.
        A build com melhor indice de valor geral fica destacada no topo.

Metodologia

      
    
        
  • Coleta: scraper/scrape_comprasparaguai.py percorre as paginas de Processador, Placa-Mae, Memoria RAM, Placa de Video, Fonte e HD/SSD e salva em data/products.json.
    • 
        
  • Especificacoes: extraidas por regex do nome de cada produto (soquete, chipset, capacidade, velocidade, wattagem, selo 80 PLUS, interface de armazenamento).
    • 
        
  • Performance de CPU/GPU: casada com a base curada em data/benchmarks.json -- por chave exata, por apelido cadastrado por voce, ou por similaridade textual (que so aceita o par quando os numeros do modelo e os sufixos tipo Ti/XT/F sao identicos).
    • 
        
  • Performance de RAM: capacidade x velocidade (MT/s, comparavel entre geracoes DDR2-5) x um fator de latencia real, calculado a partir do CAS Latency quando o anuncio informa (CL convertido para nanossegundos).
    • 
        
  • Performance de Fonte/Armazenamento/Placa-Mae: formula sobre as specs extraidas (wattagem x eficiencia, capacidade x interface, tier de chipset).
    • 
        
  • TOP Custo-Beneficio: maior indice desempenho/preco de cada categoria, ignorando o quartil mais fraco -- para nao eleger sempre a peca mais fraca e mais barata.
    • 
        
  • Montagem: a partir de cada peca TOP, as demais sao escolhidas pelo melhor indice de valor entre as opcoes compativeis e de faixa de preco equivalente.
    • 
        
  • RAM x plataforma: alem do tipo de memoria, a escolha considera a velocidade que o CPU+placa-mae realmente aproveitam (max_ram_mhz) -- um kit muito mais rapido do que a plataforma suporta tem o score reduzido, para nao pagar por MHz que ficam sem uso.
    • 
        
  • Itens nao pontuados: produtos sem specs suficientes ficam de fora automaticamente, mas podem ser revisados na pagina Base de dados e reincluidos no calculo.
    •
